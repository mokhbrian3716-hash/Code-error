# 🐞 Codex Error

**Codex Error** is a modern Persian web application designed to help programmers understand and fix common programming errors.

The application provides a simple and interactive interface where users can select a programming language and explore common errors, explanations, incorrect code examples, and corrected examples.

## 🚀 How to Run

Codex Error is a standalone HTML application and does not require installation.

Simply download the project and open:

```text
Codex error.html
```

in a modern web browser.

### Using VS Code

1. Open the project folder in Visual Studio Code.
2. Open `Codex error.html`.
3. Run the file in your browser.
4. You can also use the Live Server extension for development.

## 💾 Data & Privacy

Codex Error uses the browser's **LocalStorage** to store:

* Bookmarked errors
* Dark mode preference

No account or database is required.

Bookmark and preference data are stored locally in the user's browser.

## 📚 Error Information

Each error includes:

* Error name
* Explanation
* Incorrect code example
* Correct code example

This makes it easier for beginners to understand what caused an error and how to fix it.

## 🎯 Purpose

The goal of Codex Error is to make learning programming errors easier, especially for Persian-speaking programmers and students.

Instead of searching for every error separately, users can search within the application and quickly see an explanation with code examples.
